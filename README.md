# Employee Skills Management API

A portfolio project built with ASP.NET Core Web API to manage employees, departments, skills, and proficiency levels.

This project is inspired by a skills management application I worked with professionally and is designed to strengthen my backend development skills within the Microsoft ecosystem.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Swagger / OpenAPI
- Git & GitHub

## Features

### Current Features
- ASP.NET Core Web API project setup
- Entity Framework Core integration
- SQLite database
- Department entity and CRUD endpoints
- Swagger API documentation

### Planned Features
- Employee management
- Skill management
- Employee skill tracking
- Skill proficiency levels
- Search and filtering
- DTOs and validation
- Service layer implementation
- Authentication and authorization (future enhancement)
